Add Page Numbers to a PDF

Number every page in the position and format you choose. Processed locally — nothing is uploaded.

Use {n} for the page number and {total} for the total page count — e.g. "Page {n} of {total}" or just "{n}".

How it works

  1. Add a PDF file.
  2. Choose a position, format, starting number and font size.
  3. Click "Add Page Numbers" to download the numbered PDF.
