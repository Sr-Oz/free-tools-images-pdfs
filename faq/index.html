Frequently asked questions

Everything people usually ask before trusting a "free online" file tool.

Is this actually free?

Yes. No account, no email gate, no watermark on your output files, and no paywalled features. Everything on the site today is free to use.

Do you store or see my files?

No. Every tool runs as JavaScript inside your own browser tab. Your files are read locally, processed locally, and downloaded locally — they are never uploaded to a server, because these tools don't have one.

Do I need to create an account?

No. There's no sign-up, login, or email required for any tool.

Does it work without an internet connection?

Once a tool page has fully loaded, yes — you can disconnect from the internet and keep using it, since all processing happens locally. You do need a connection to load the page itself the first time.

Is there a file size limit?

There's no artificial limit imposed by the site. The practical limit is your device's memory and browser, since your files are processed locally rather than on a server — very large PDFs or images may be slower on lower-powered devices.

Which browsers are supported?

Recent versions of Chrome, Firefox, Edge and Safari. The tools use standard modern browser features (Canvas, Web Workers, ES modules), so keeping your browser up to date helps.

Will my output be watermarked or quality-reduced?

No forced watermarks, ever. Compression and quality settings (where applicable) are controlled by you via sliders in each tool.

Do you use analytics, ads, or tracking?

Not currently. See the Privacy Policy for the full, up-to-date picture.

Can I use this for sensitive or confidential documents?

Because files never leave your browser, there's no upload step that could expose them in transit or on a server. You're still responsible for the security of your own device.

I found a bug or want a new tool — what do I do?

Open an issue on GitHub using the bug report or feature request template. The project is open source and welcomes contributions.
