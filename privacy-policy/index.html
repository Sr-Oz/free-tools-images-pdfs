Privacy Policy

Last updated: August 2026

Your files

None of the tools on this site have a server component. Every compression, conversion, merge, split, or edit runs as JavaScript inside your own browser tab, using the open-source libraries pdf-lib and pdf.js, which are hosted on this site rather than fetched from a third party at runtime. Your files are never transmitted anywhere — they stay on your device from the moment you select them to the moment you download the result.

Accounts and personal data

There is no sign-up, login, or account system, and the site does not ask for your name, email, or any other personal information.

Cookies and local storage

The site does not set cookies and does not use browser local storage or session storage to track you.

Analytics and advertising

As of this writing, the site runs no analytics (no Google Analytics, no Plausible, no similar service) and shows no ads. If that ever changes, this page will be updated first, and any analytics added will be disclosed here along with what it collects.

Hosting

This site is hosted on GitHub Pages. Like any web host, GitHub's servers necessarily process standard connection information (such as your IP address) to deliver the page to you — this is outside this project's control and is covered by GitHub's own privacy statement. This project itself does not access or log that information.

Third-party links

Pages on this site link out to external sites (for example, the GitHub repository and the pdf-lib/pdf.js project pages). Those sites have their own privacy practices, which this policy doesn't cover.

Changes to this policy

If this policy changes in a way that affects what data is collected, the "Last updated" date above will change and the update will be visible in the project's public commit history.

Questions

Open an issue on GitHub.
