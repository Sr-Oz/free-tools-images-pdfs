Compress PDF

Reduce PDF file size without leaving your browser.

📉
Drop a PDF here or click to choose
One PDF file

Strong compression re-renders every page as a compressed image. This works great for scanned documents and image-heavy PDFs, but selectable text will become part of the image (no longer searchable/selectable). Try Quick clean first if your PDF is mostly text.

How it works

  1. Add a PDF file.
  2. Choose Quick clean for a lossless-ish pass, or Strong compression for maximum size reduction.
  3. Click "Compress PDF" and download the result.
