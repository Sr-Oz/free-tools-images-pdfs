Why these tools are actually private

Most "free online" file tools quietly upload your document to a server to process it. This site doesn't have a server at all for these tools — every conversion, compression and edit runs locally in JavaScript inside your own browser tab using open-source libraries (pdf-lib and pdf.js). Your files are never transmitted anywhere. You can even disconnect from the internet after the page loads and the tools still work.
