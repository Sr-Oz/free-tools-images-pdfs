Extract Text from a PDF

Pull all the text out of a PDF so you can copy, search, or reuse it. Processed locally — nothing is uploaded.

How it works

  1. Add a PDF file.
  2. The text from every page is extracted and shown below, ready to copy.
  3. Copy it directly, or download the whole thing as a plain text file.

This pulls text that's already embedded in the PDF (like from a Word export). It won't extract text from a scanned image — that needs OCR, which isn't available on this site yet.
