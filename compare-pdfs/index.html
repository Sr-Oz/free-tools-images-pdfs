How it works

  1. Add the original PDF on the left and the revised one on the right.
  2. Click "Compare" — text is extracted from both and compared line by line.
  3. Added lines are highlighted green, removed lines red.

This compares extracted text, not visual layout — formatting-only changes (font, color, spacing) won't show up, only actual text differences will.
