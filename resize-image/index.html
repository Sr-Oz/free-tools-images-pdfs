Resize Image

Resize by exact pixel dimensions or by percentage. Processed locally — nothing is uploaded.

aspect_ratio
Drop images here or click to choose
JPEG, PNG or WebP · multiple files supported

    Tip: for multiple images with different original sizes, percentage mode scales each proportionally; pixel mode applies the same target size to all.

    How it works

    1. Add one or more images.
    2. Choose to resize by exact width/height or by a percentage scale.
    3. Click "Resize Images" and download each result.
