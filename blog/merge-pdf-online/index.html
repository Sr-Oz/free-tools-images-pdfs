How to Merge PDF Files Online for Free

Published 14 August 2026 · 3 min read

Merging PDFs is one of those tasks that comes up more than you'd expect: combining scanned receipts into one file for expenses, stitching a cover letter onto a resume, or pulling several chapters of a report into a single document before sending it. You don't need desktop software or a paid subscription for this — a browser and a couple of files is enough.

Step by step

  1. Open the Merge PDF tool.
  2. Drop in two or more PDF files, or click to choose them from your device.
  3. Use the ↑ / ↓ buttons next to each file to put them in the order you want the merged document to read.
  4. Click "Merge PDFs." The combined file downloads straight away.

A few practical tips

  • Order matters and won't fix itself. The tool merges files in the exact order shown in the list, so double-check it before merging — there's no "sort by name" magic happening behind the scenes.
  • Page count adds up, file size doesn't always. A merged PDF's size is roughly the sum of its parts; if the result feels too large, run it through Compress PDF afterward.
  • Nothing is uploaded. The merge happens in your browser using the open-source pdf-lib library — your files never touch a server, which matters if any of the documents are sensitive.
